Настройки GGPoisk Button

Список зеркал для проверки. Каждое зеркало — на отдельной строке. Проверка идёт сверху вниз, открывается первое доступное.

Как это работает
  • Указывайте только домен, без https:// и без пути.
  • Пример: kinokino.win
  • Порядок строк = порядок проверки. Первое рабочее зеркало откроется.
  • Можно добавить любое зеркало, работающее по схеме https://домен/film/123/.
  • При добавлении нового домена Firefox спросит разрешение на доступ к сайтам — это нужно для проверки доступности.
