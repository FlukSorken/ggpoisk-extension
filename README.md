# GGPoisk Button

Расширение для Firefox, которое добавляет кнопку «Смотреть» на страницах
фильмов и сериалов Кинопоиска. При нажатии расширение проверяет доступность
зеркал (ggpoisk.ru → sspoisk.ru) и открывает то, которое отвечает.

## Установка

После публикации на AMO:

[Firefox Add-ons](https://addons.mozilla.org/ru/firefox/addon/ggpoisk-button/)

Или вручную (для разработки):
1. Склонируйте репозиторий.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. «Загрузить временное дополнение» → выберите `manifest.json`.

## Как это работает

1. На странице фильма/сериала Кинопоиска появляется кнопка в правом нижнем углу.
2. Клик → background-скрипт пингует `ggpoisk.ru` с таймаутом 4 секунды.
3. Если ggpoisk не отвечает — пробует `sspoisk.ru`.
4. Открывает рабочее зеркало в новой вкладке.
