# GGPoisk Button

Расширение для Firefox, которое добавляет кнопку «Смотреть» на страницах
фильмов и сериалов Кинопоиска. При нажатии расширение проверяет доступность
зеркал и открывает то, которое отвечает.

## Установка

[Firefox Add-ons](https://addons.mozilla.org/ru/firefox/addon/ggpoisk-button/)

Или вручную (для разработки):
1. Склонируйте репозиторий.
2. Откройте `about:debugging#/runtime/this-firefox`.
3. «Загрузить временное дополнение» → выберите `manifest.json`.

## Как это работает

1. На странице фильма/сериала Кинопоиска появляется кнопка в правом нижнем углу.
2. Клик → background-скрипт проверяет зеркала по порядку (по умолчанию:
   `kinokino.win` → `ggpoisk.ru` → `sspoisk.ru`) с таймаутом 4 секунды на каждое.
3. Открывает первое доступное зеркало в новой вкладке.

## Настройки

Список зеркал можно менять: `about:addons` → **GGPoisk Button** → **Настройки**.
Каждое зеркало — на отдельной строке. Порядок строк = порядок проверки.
Можно добавлять любые домены, работающие по схеме `https://домен/film/123/`.

При добавлении нового домена Firefox запросит разрешение на доступ к сайтам.

## Приватность

Расширение не собирает, не хранит и не передаёт никакие пользовательские данные.
Проверка доступности зеркал выполняется без отправки куки
(`credentials: 'omit'`) и без какой-либо идентификации пользователя.
